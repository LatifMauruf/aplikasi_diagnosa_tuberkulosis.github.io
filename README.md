## Installation

Clone repository:

```bash
git clone https://github.com/LatifMauruf/aplikasi_diagnosa_tuberkulosis.github.io.git
```

Move to project folder:

```bash
cd tb-diagnosis-system
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run application:

```bash
python app.py
```
